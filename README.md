# Community Gardens Visualization (Works Offline)

This version is designed to **work immediately** in a browser without internet.

## Open it

- Double-click `index.html`, or
- Serve locally:

```bash
python3 -m http.server 8000
```

Then open: `http://localhost:8000/index.html`

## What you get

- Interactive schematic map of Aberdeen + North East Scotland
- Hover tooltips with garden details
- Filters by area, feature, and name
- Live summary stats and visible-garden list

No external map libraries or tile servers are required.
